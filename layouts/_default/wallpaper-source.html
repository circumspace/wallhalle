Neither macOS nor Linux desktops subscribe to a web address for wallpapers, but both rotate through a folder. So the site publishes plain lists of download links, one per screen size, and you sync a list into a folder once in a while.

Each list holds one absolute URL per line and only paintings whose cut fills that size. Lists grow as paintings are added; re-running a sync fetches the whole list again.

macOS

Downloads every 5K 16:9 cut into ~/Pictures/wallpaintr. Swap the list name for another size.

mkdir -p ~/Pictures/wallpaintr && curl -sZ --remote-name-all --output-dir ~/Pictures/wallpaintr $(curl -s {{ "/lists/5k-16x9.txt" | absURL }})

Then System Settings, Wallpaper, Add Folder or Album, pick the folder and turn on rotation.

Omarchy

Omarchy cycles through ~/.config/omarchy/backgrounds/<theme>/ with Super+Ctrl+Space. This fills the folder of the theme currently active.

theme=$(basename "$(readlink ~/.config/omarchy/current/theme)") && mkdir -p ~/.config/omarchy/backgrounds/$theme && curl -sZ --remote-name-all --output-dir ~/.config/omarchy/backgrounds/$theme $(curl -s {{ "/lists/5k-16x9.txt" | absURL }})

Other Linux desktops: point the wallpaper slideshow at any folder you sync the same way.

Everything, as JSON

index.json lists every painting with title, artist, licence, source, original and all cuts with their pixel sizes, byte counts and URLs, plus which tier each cut fills. Build your own picker from it.

A full 6K list is around 700 MB. Start with one list, not all four.
